# Native interface direction

Source: the user's existing Frostbound browser identity and their requests for readable, nongeneric game UI. This is a transcription of the existing project's visual direction, not a new brand proposal.

Snow and slate form the world palette. Furnace amber marks warmth and primary actions. Oxanium carries the existing blocky field-kit typography. The native HUD uses compact, opaque slate surfaces so supplies and survival numbers remain readable over white snow. The furnace and survivor remain the scene's focal point. Resource names and numeric values communicate state without relying on color alone.

Menus use task-specific actions and plain descriptions of actual preview behavior. No claims of full migration or unsupported mechanics appear in the interface. Menus pause gameplay; food controls explain the paused shared cooldown. All visible buttons perform an implemented action. Mouse and keyboard paths are provided; full screen-reader/accessibility parity is pending.

Antislop mode: during (explicit session choice). ENERGY 2 / RHYTHM 2 / MOTION 1. Deliberate locomotion, combat and fire communicate game state; no decorative menu animation is needed. No new generated assets or external visual libraries are introduced. Existing models and font are reused.
